# Video production kit

The [finished Episode 1 video package](episode_01_video_package.md) includes the MP4, captions, thumbnail, upload text, and editable render project.

Start with the [long-form series plan](youtube_series_plan.md), then follow the [free-tool creator guide](youtube_creator_guide.md) and the [Episode 1 recording script](episode_01_full_tutorial.md). Each chapter is designed to be recorded separately with screen capture and voice; no camera is required.

The older [16–18 minute flagship script](youtube_flagship_script.md) and its [interactive demo runner](run_flagship_demo.py) remain available as a shorter overview.
